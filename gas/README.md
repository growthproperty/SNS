# SNS Bot セットアップ手順

**かかる費用: Anthropic APIのみ（月100〜300円）。サーバー代は0円。**

全部で8ステップ。慣れていなくても30〜40分あれば完了します。

---

## 事前に用意するもの

| 必要なもの | 入手先 | 費用 |
|---|---|---|
| Googleアカウント | 持っていればOK | 無料 |
| LINEアカウント | 持っていればOK | 無料 |
| Anthropic APIキー | https://console.anthropic.com | 無料登録・従量課金 |

---

## STEP 1｜Anthropic APIキーを取得する

1. https://console.anthropic.com にアクセス
2. 「Sign Up」でアカウント作成（メールアドレスで登録）
3. ログイン後、左メニューの **「API Keys」** をクリック
4. **「Create Key」** ボタンをクリック
5. 名前は何でもOK（例: `SNS Bot`）→ **「Create Key」**
6. 表示された `sk-ant-api03-...` という文字列を**必ずメモ帳にコピー**しておく
   > ⚠️ この画面を閉じると二度と表示されません

---

## STEP 2｜Googleスプレッドシートを作る（データ保存先）

1. https://sheets.google.com にアクセス（Googleアカウントでログイン）
2. 左上の **「＋ 新しいスプレッドシート」** をクリック
3. 左上のタイトル部分（「無題のスプレッドシート」）をクリックして **「SNS Bot データ」** と入力してEnter
4. 今開いているページのURLを見る：
   ```
   https://docs.google.com/spreadsheets/d/★ここをコピー★/edit
   ```
   `d/` と `/edit` の間の文字列（例: `1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms`）を**メモ帳にコピー**する

---

## STEP 3｜Apps Scriptにコードを貼り付ける

1. スプレッドシートを開いたまま、上のメニューの **「拡張機能」** をクリック
2. **「Apps Script」** をクリック（新しいタブで開く）
3. 左側のファイル一覧に **「コード.gs」** があることを確認
4. 右側のコードエリアに `function myFunction() {...}` という初期コードが書いてあるので、**全部選択（Ctrl+A）して削除**
5. このリポジトリの **`gas/Code.gs`** ファイルを開いて、内容を**全部コピー（Ctrl+A → Ctrl+C）**
6. Apps Scriptのコードエリアに**貼り付け（Ctrl+V）**
7. 上部のフロッピーディスクアイコン（または **Ctrl+S**）で**保存**
   > 「プロジェクト名を変更しますか？」と聞かれたら「SNS Bot」と入力してOK

---

## STEP 4｜APIキーなどをスクリプトプロパティに設定する

コードに直接APIキーを書かず、安全に設定する方法です。

1. Apps Script 画面の左メニューにある **歯車アイコン（⚙）「プロジェクトの設定」** をクリック
2. ページを下にスクロールして **「スクリプト プロパティ」** セクションを見つける
3. **「スクリプト プロパティを追加」** をクリック
4. 以下の3つを1つずつ追加する（「プロパティ」と「値」を入力して「保存」）：

---

**1つ目：**
- プロパティ: `ANTHROPIC_API_KEY`
- 値: STEP 1 でコピーした `sk-ant-...` のキー

**2つ目：**（LINE設定後に戻って入力してもOK）
- プロパティ: `LINE_CHANNEL_ACCESS_TOKEN`
- 値: STEP 5 で取得するトークン（後で入力）

**3つ目：**
- プロパティ: `SPREADSHEET_ID`
- 値: STEP 2 でコピーしたスプレッドシートのID

---

5. 3つ全部入力したら **「スクリプト プロパティを保存」** をクリック

---

## STEP 5｜LINE公式アカウント（Bot）を作る

1. https://developers.line.biz/ja/ にアクセスして **「ログイン」**（LINEアカウントで）
2. **「プロバイダーを作成」** をクリック
   - プロバイダー名: 何でもOK（例: `自分の名前`）
3. **「新規チャンネル作成」** → **「Messaging API」** を選択
4. 以下を入力して作成：
   - チャンネルの種類: `Messaging API`（選択済みのはず）
   - プロバイダー: 先ほど作成したプロバイダー
   - チャンネルアイコン: スキップでOK
   - チャンネル名: `SNS Bot`（LINE上で表示される名前）
   - チャンネル説明: 適当でOK
   - 大業種: `個人`
   - 小業種: `個人（その他）`
   - メールアドレス: 自分のアドレス
5. 利用規約にチェックして **「作成」**

6. 作成されたチャンネルの **「Messaging API 設定」** タブをクリック
7. 一番下までスクロールして **「チャンネルアクセストークン（長期）」** の **「発行」** ボタンをクリック
8. 表示された長い文字列を**メモ帳にコピー**
9. STEP 4 に戻って `LINE_CHANNEL_ACCESS_TOKEN` の値として入力・保存する

---

## STEP 6｜セットアップ関数を実行する

1. Apps Script の画面に戻る
2. 上部の関数選択プルダウン（`myFunction ▼` みたいなところ）をクリック
3. **`setup`** を選んで **「▶ 実行」** ボタンをクリック
4. **「承認が必要です」** というダイアログが出たら：
   - 「権限を確認」をクリック
   - Googleアカウントを選択
   - 「このアプリはGoogleで確認されていません」と警告が出たら → **「詳細」** をクリック → **「SNS Bot（安全ではないページ）に移動」** をクリック
   - 「許可」をクリック
5. 画面下部の **「実行ログ」** に `✅ セットアップ完了！` と表示されればOK

---

## STEP 7｜ウェブアプリとして公開する（LINE用のURLを取得）

1. Apps Script 画面の右上 **「デプロイ」** ボタンをクリック
2. **「新しいデプロイ」** をクリック
3. 左上の歯車アイコン（⚙）をクリックして **「ウェブアプリ」** を選択
4. 設定を以下のように変更：
   - 説明: `SNS Bot`（任意）
   - **次のユーザーとして実行: 「自分（自分のメールアドレス）」**
   - **アクセスできるユーザー: 「全員」**
5. **「デプロイ」** をクリック → 再度「許可」
6. **「ウェブアプリ」のURL**（`https://script.google.com/macros/s/★★★/exec` という形式）を**メモ帳にコピー**

---

## STEP 8｜LINEのWebhookにURLを設定して友達追加

1. https://developers.line.biz/ja/ → 作成したチャンネルを開く
2. **「Messaging API 設定」** タブをクリック
3. **「Webhook URL」** の欄に STEP 7 でコピーした URL を貼り付けて **「更新」**
4. **「検証」** ボタンをクリック → **「成功」** と表示されればOK
5. **「Webhookの利用」** のトグルを **オン** にする
6. **「LINE公式アカウント機能」** のところで **「応答メッセージ」→「編集」** をクリック
   - LINE Official Account Managerが開くので「応答メッセージ」を **オフ** にする
   - 「あいさつメッセージ」もオフ推奨

**友達追加・グループ招待：**

- **個人トークで使う場合：** 「Messaging API 設定」のQRコードをスマホで読んで友達追加
- **LINEグループで使う場合：**
  1. 「Messaging API 設定」の **「グループ・複数人トークへの参加を許可する」** をオンにする
  2. LINEのグループを開いて **「メンバーを招待」** → Botのアカウント名で検索して招待

---

## 完成！動作確認

LINEで以下を送ってみましょう：

```
help
```

↓ こんな返信が来ればセットアップ成功です

```
📖 SNS Bot 使い方

URLを送信
→ 投稿を保存して引用コメント5案を生成

コマンド:
list → 最近の投稿を一覧表示
...
```

次に実際にURLを送ってみましょう：

```
https://note.com/～～～（気になった記事のURL）
```

「🔍 コンテンツを取得中...」と返ってきて、**1〜2分後**に引用コメント5案が届きます。

---

## 使い方まとめ

| 送るもの | 何が起きるか |
|---|---|
| `https://...`（URL） | 投稿を保存 → 引用コメント5案を生成（1〜2分後） |
| `list` | 保存済み投稿の一覧を表示 |
| `show 3` | ID:3の投稿の詳細とコメントを表示 |
| `generate 3` | ID:3のコメントを再生成（1〜2分後） |
| `original` | 蓄積した投稿をもとにオリジナルポスト5案を生成（1〜2分後） |
| `help` | 使い方を表示 |

## よくあるトラブル

### ❓ 「検証」を押したら失敗する

→ STEP 7 の URL が正しくコピーできているか確認。URL の末尾が `/exec` になっているか確認。

### ❓ 返信が「🔍 取得中...」で止まってコメントが来ない

→ STEP 6 の `setup` 関数を実行し忘れている可能性があります。
Apps Script を開いて `setup` を選択し、もう一度「▶ 実行」してください。

### ❓ X（Twitter）のURLを送ったら「取得に失敗」と言われる

→ Xの投稿はログインしていないと内容が取れないことがあります。
その場合は **投稿本文をコピーして直接LINEに貼り付けて送信**すれば、そのテキストを元にコメントを生成できます（URL貼り付けでなくテキスト入力として）。
※ ただしXのテキスト入力はコマンド扱いになるので、将来的に対応追加予定。

### ❓ APIキーはどこに保存されている？

→ Google Apps Script の「スクリプト プロパティ」に暗号化されて保存されます。
コードには一切含まれていないので、コードを誰かに見せても漏洩しません。
